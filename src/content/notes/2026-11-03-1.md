```css
ul { text-align: center; padding: 0; }
li { display: inline; }
li::after {
 content: ' ';
 word-spacing: 1rem;
 background-image: linear-gradient(-.2turn,
  transparent 0 calc(50% - .03em),
  currentcolor 0 calc(50% + .03em),
  transparent 0);
}
```
