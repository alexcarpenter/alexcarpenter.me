---
title: Clever property usage to create a light-dark probe
link: https://x.com/thomas_sweet/status/2082201527234531388?s=46
published: 2026-07-29T10:23:31-0400
---

```css
@property --scheme-probe {
  syntax: "<color>";
  inherits: true;
  initial-value: white;
}

.card {
  --scheme-probe: light-dark(white, black);
}

@container style(--scheme-probe: black) {
  .swatch {
    border-style: dashed; /* any property */
  }
}
```
